¿Qué es el DOM?

El DOM (Document Object Model) es una representación en forma de árbol de todos los elementos HTML de una página. Cada etiqueta se convierte en un nodo que cuelga de un nodo padre, formando una jerarquía que el navegador usa para renderizar y manipular el contenido.

A continuación se muestra el árbol del DOM de las 3 páginas principales de este proyecto. Pasa el cursor sobre cada nodo para resaltarlo.
