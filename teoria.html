1. La etiqueta HTML <canvas>

La etiqueta <canvas> es un elemento HTML5 que proporciona una superficie de dibujo bidimensional (o 3D con WebGL) controlada desde JavaScript. Es ideal para gráficos, animaciones, videojuegos y visualización de datos.

1.1 Sintaxis básica

<canvas id="miCanvas" width="400" height="300">
    Tu navegador no soporta canvas.
</canvas>

1.2 Obtener el contexto de renderizado 2D

El "contexto" es el objeto que expone todos los métodos de dibujo. Para 2D se obtiene así: 

const canvas = document.getElementById("miCanvas");
const ctx = canvas.getContext("2d");

1.3 Métodos más usados del contexto 2D

  • fillRect(x, y, w, h) → dibuja un rectángulo relleno.
  • strokeRect() → dibuja el borde de un rectángulo.
  • beginPath() y closePath() → inician/cierran un trazo.
  • arc(x, y, radio, inicio, fin) → dibuja círculos o arcos.
  • fillStyle y strokeStyle → color de relleno y borde.
  • fillText() → escribe texto en el canvas.

1.4 Ejemplo práctico: dibujar un círculo

const c = document.getElementById("demoCanvas");
const ctx = c.getContext("2d");
ctx.fillStyle = "tomato";
ctx.beginPath();
ctx.arc(150, 100, 60, 0, Math.PI * 2);
ctx.fill();

2. La librería p5.js

p5.js es una biblioteca de JavaScript basada en Processing que simplifica el dibujo sobre canvas. Fue creada para artistas, diseñadores y principiantes. Khan Academy la usa en su curso de "Computer Programming".

2.1 ¿Cómo se incluye?

<script src="https://cdn.jsdelivr.net/npm/p5@2/lib/p5.min.js"></script>

2.2 Estructura básica de un sketch

function setup() {
    createCanvas(400, 400);  // se ejecuta una vez
}

function draw() {
    background(220);          // se ejecuta en bucle ~60 fps
    ellipse(200, 200, 100, 100);
}

2.3 Funciones clave

  • setup(): configuración inicial (tamaño, colores base).
  • draw(): se repite continuamente (animaciones).
  • mouseX, mouseY: posición del ratón (interactividad).
  • random(), noise(): números aleatorios y ruido.
  • rotate(), translate(), scale(): transformaciones.
